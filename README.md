# Zilpah

Marketing site and working notes for Zilpah, a B2B outbound-growth agency.

- `zilpah-site/` — the static Zilpah.io website (`index.html`, `brief.html`, shared CSS/JS, fonts, images). No build step; serve the folder as-is. `_headers` sets security headers on static hosts that support a `_headers` file.
- `design/DESIGN.md` — design system and visual guidelines.
- `audit/` — site audit and security review, with screenshots in `audit/img/`.
- `THIRD_PARTY_NOTICES.md` — licences for the font and the ported UI components.
